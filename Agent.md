# 🤖 AI Agent Configuration & Guidelines

This document outlines the context and guidelines for AI agents working within this repository.

## 📁 Repository Context
This repository contains exercises, assignments, and projects for the **Purwadhika Fullstack Web Development Bootcamp**. It is organized logically into modules covering distinct topics:
- **Module 1**: Programming Fundamentals (JavaScript, TypeScript, Algorithms)
- **Module 2**: Front End Web Development (HTML, CSS, React, State Management)
- **Module 3**: Back End Development (Node.js, Express, REST API, PostgreSQL Database, ORM Tools, Prisma, Monorepo Architecture, AI Assisted Development)

## 🛠️ Agent Responsibilities
1. **Maintain Code Structure**: Always place new projects or exercises in their respective module and submodule folders. Use clear naming conventions.
2. **Sync Documentation**: Whenever new exercises or modules are introduced, ensure that `README.md` and the frontend landing page (`index.html`) are accurately updated.
3. **Ensure Code Quality**: Write clean, modern, and production-ready code. Adhere to specified tech stacks for each module.
4. **Follow Workflows**: Utilize the GitHub actions defined in `.github/workflows/` and respect the deployment pipelines.
